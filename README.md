# Text Editor

A simple Java Swing text editor for opening, editing, saving, and replacing text in `.txt` files.

## Features

- Open a text file
- Edit text
- Save changes
- Replace text in the file
- Close the app

## Run the project

Make sure Java is installed.

```bash
javac src/*.java
java -cp src Main
```

## Files

```text
src/
├── Main.java
└── TextEditorWindow.java
```

This app uses Java Swing to create the desktop window and editor interface.
